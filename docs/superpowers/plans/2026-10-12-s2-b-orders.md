# S2 Sub-project B — Orders list and Order view Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Orders tab of the Orders section, built to the v2 mockup: a BC-filtered, paged list of the customer's `SOR` Sales Orders and an Order view dialog with lines and the Trip ID note.

**Architecture:** One `orders` Server Logic (list + detail) built on the generated BC helpers, scoped only from the session; BC does the filtering and paging, search merges parallel queries because BC can't `or` two fields. The SPA keeps filters in the URL, reuses sub-project A's list kit, and adds a `Pager`, a `DatePicker`, peso/date formatters and an Order dialog.

**Tech Stack:** Power Pages Server Logic (JS, no modules), BC API `api/pasi/mcrm/v1.0` (`mcrmSalesOrders`, `chpSalesOrderLines`), React 19 + Vite + TypeScript, Tailwind v4, shadcn/ui (`select`, `popover`, `calendar`, existing `dialog`), TanStack Query 5 (`keepPreviousData`), TanStack Table v9 (existing `DataTable`), date-fns, Vitest + React Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-12-s2-b-orders-design.md`

## Global Constraints

- Architecture rules in `CLAUDE.md`: the browser never calls BC; every BC call is scoped from `sessionScope()`, never from the request; every user value in an OData `$filter` goes through `odataLiteral()`; no business math in the SPA (totals and line totals come from BC).
- Server Logic: arrow callbacks only; no `require`/`import`/`eval`/`setTimeout`/`delete`/`prototype`/`Reflect.`; only `get` at the top level (helpers nested inside); the `#region bc-helpers` block is generated — run `node scripts/stamp-server-logic-helpers.mjs` after creating the file.
- Only the `SOR` number series is listed: `startswith(salesOrderNo,'SOR')` (BC rejects `not`; the API also returns `BSO…`, `SCM…`, `SIN…`).
- BC limits: no `or` across different fields; `contains` is case-sensitive; `$count`, `$top`, `$skip`, `$orderby`, `startswith`, `contains`, date `ge/le` work.
- Status, Pick up/Delivery, Trip ID, expected delivery and Blanket SO # come back `null` when BC has no value; the SPA shows "—". Status dropdown is hidden while every returned order has `status: null`.
- Out of scope: other Orders tabs, + New Order, + New Multiple Order, CSV / Excel, Reorder (Order view has **Close** only).
- Copy is the mockup's wording. New copy (wording checklist): *You don't have any orders yet.* · *We couldn't find this order.* · *No items on this order.*
- Every page sets `usePageTitle('Orders')` → "Orders — Concreat Connect".

```js
// Server Logic: orders (S2-04)
// Purpose: the signed-in customer's BC Sales Orders — list (filtered and paged in BC) and detail with lines.
// API URL: https://<site>/_api/serverlogics/orders?q=&site=&from=&to=&page=  ·  ?id=SOR…
// Customer and company come only from the session's Account; request values only narrow the list.

async function get() {
    // #region bc-helpers (generated from server-logic-src/bc-helpers.js — do not edit)
    // #endregion bc-helpers

    // mcrmSalesOrders also returns blanket (BSO), credit memo (SCM) and invoice (SIN) documents and has no document
    // type; BC rejects "not", so only the SOR series is listed. Switch to documentType eq 'Order' when BC adds it.
    var SO_SERIES = "SOR";
    var PAGE_SIZE = 10;
    var SEARCH_CAP = "200";
    var ORDER_FIELDS = "salesOrderNo,sellToCustomerNo,orderDate,externalDocumentNo,shiptoCode,shipmentMethodCode,tripEntryNo,requestDeliveryDate,totalAmountInclVAT";
    var LINE_FIELDS = "documentNo,itemNo,description,quantity,unitOfMeasureCode,unitPrice,AmountIncludingVAT";
    var ISO_DATE = /^\d{4}-\d{2}-\d{2}$/;

    function param(name) {
        var params = Server.Context.QueryParameters || {};
        var value = params[name];
        return value === undefined || value === null ? "" : String(value).trim();
    }

    function bcDate(value) {
        return value && value !== "0001-01-01" ? value : null;
    }

    function owned(row, scope) {
        return row.sellToCustomerNo === scope.customerNo && String(row.salesOrderNo || "").indexOf(SO_SERIES) === 0;
    }

    function newestFirst(a, b) {
        if (a.orderDate !== b.orderDate) {
            return a.orderDate < b.orderDate ? 1 : -1;
        }
        return a.salesOrderNo < b.salesOrderNo ? 1 : a.salesOrderNo > b.salesOrderNo ? -1 : 0;
    }

    // Status, ship (Pick up / Delivery), Blanket SO # and the Trip ID assigned date stay null until BC provides them (S2-03).
    function toSummary(row) {
        return {
            so: row.salesOrderNo,
            date: row.orderDate || "",
            po: row.externalDocumentNo || "",
            site: row.shiptoCode || "",
            ship: null,
            bso: null,
            trip: row.tripEntryNo ? { id: row.tripEntryNo, assignedAt: null } : null,
            edd: bcDate(row.requestDeliveryDate),
            total: Number(row.totalAmountInclVAT) || 0,
            status: null
        };
    }

    function toLine(row) {
        return {
            code: row.itemNo || "",
            description: row.description || "",
            qty: Number(row.quantity) || 0,
            uom: row.unitOfMeasureCode || "",
            unitPrice: Number(row.unitPrice) || 0,
            lineTotal: Number(row.AmountIncludingVAT) || 0
        };
    }

    function listFilter(scope) {
        var parts = ["sellToCustomerNo eq " + odataLiteral(scope.customerNo), "startswith(salesOrderNo," + odataLiteral(SO_SERIES) + ")"];
        var site = param("site");
        var from = param("from");
        var to = param("to");
        if (site) {
            parts.push("shiptoCode eq " + odataLiteral(site));
        }
        // Dates go into the filter unquoted, so only an exact YYYY-MM-DD is accepted.
        if (ISO_DATE.test(from)) {
            parts.push("orderDate ge " + from);
        }
        if (ISO_DATE.test(to)) {
            parts.push("orderDate le " + to);
        }
        return parts.join(" and ");
    }

    async function detail(scope, id) {
        if (id.indexOf(SO_SERIES) !== 0) {
            return { notFound: true };
        }
        var found = await bcGet(
            scope,
            "mcrmSalesOrders",
            odataQuery({
                $filter: "salesOrderNo eq " + odataLiteral(id) + " and sellToCustomerNo eq " + odataLiteral(scope.customerNo),
                $select: ORDER_FIELDS
            })
        );
        var order = ((found && found.value) || []).find((row) => row.salesOrderNo === id && owned(row, scope));
        // Another customer's order gets the same answer as a missing one.
        if (!order) {
            return { notFound: true };
        }
        var lines = await bcGet(
            scope,
            "chpSalesOrderLines",
            odataQuery({ $filter: "documentNo eq " + odataLiteral(id), $select: LINE_FIELDS, $top: "500" })
        );
        var dto = toSummary(order);
        dto.lines = ((lines && lines.value) || []).filter((line) => line.documentNo === id).map(toLine);
        return dto;
    }

    async function list(scope, page) {
        var filter = listFilter(scope);
        var q = param("q").slice(0, 50);
        if (!q) {
            var result = await bcGet(
                scope,
                "mcrmSalesOrders",
                odataQuery({
                    $filter: filter,
                    $select: ORDER_FIELDS,
                    $orderby: "orderDate desc,salesOrderNo desc",
                    $top: String(PAGE_SIZE),
                    $skip: String((page - 1) * PAGE_SIZE),
                    $count: "true"
                })
            );
            var rows = ((result && result.value) || []).filter((row) => owned(row, scope));
            var count = Number(result && result["@odata.count"]);
            return { orders: rows.map(toSummary), total: isNaN(count) ? rows.length : count, page: page, pageSize: PAGE_SIZE };
        }
        // BC can't "or" two fields and contains() is case-sensitive: search the SO number (upper case) and the PO
        // reference (as typed and upper case) separately, then merge.
        var upper = q.toUpperCase();
        var terms = [["salesOrderNo", upper], ["externalDocumentNo", q]];
        if (upper !== q) {
            terms.push(["externalDocumentNo", upper]);
        }
        var results = await Promise.all(
            terms.map((term) =>
                bcGet(
                    scope,
                    "mcrmSalesOrders",
                    odataQuery({ $filter: filter + " and contains(" + term[0] + "," + odataLiteral(term[1]) + ")", $select: ORDER_FIELDS, $top: SEARCH_CAP })
                )
            )
        );
        var merged = [];
        results.forEach((res) => {
            ((res && res.value) || []).forEach((row) => {
                if (owned(row, scope) && !merged.some((seen) => seen.salesOrderNo === row.salesOrderNo)) {
                    merged.push(row);
                }
            });
        });
        merged.sort(newestFirst);
        var start = (page - 1) * PAGE_SIZE;
        return { orders: merged.slice(start, start + PAGE_SIZE).map(toSummary), total: merged.length, page: page, pageSize: PAGE_SIZE };
    }

    Server.Logger.Log("orders GET called");
    return respond(async () => {
        var scope = await sessionScope();
        var id = param("id");
        if (id) {
            return detail(scope, id);
        }
        var page = parseInt(param("page"), 10);
        return list(scope, isNaN(page) || page < 1 ? 1 : Math.min(page, 1000));
    });
}

import { format, isValid, parseISO } from 'date-fns'

const PESO = new Intl.NumberFormat('en-PH', { minimumFractionDigits: 2, maximumFractionDigits: 2 })

/** ₱1,234.00; negatives as -₱1,234.00 (DESIGN.md, the way BC shows credits). Display only — amounts come from BC. */
export function peso(value: number): string {
  return (value < 0 ? '-₱' : '₱') + PESO.format(Math.abs(value))
}

/** Oct 9, 2026. "—" for an empty value, BC's 0001-01-01 "no date", or anything unparseable. */
export function formatDate(iso: string | null | undefined): string {
  if (!iso || iso === '0001-01-01') return '—'
  const date = parseISO(iso)
  return isValid(date) ? format(date, 'MMM d, yyyy') : '—'
}

/** Wireframe `.pager`: "Showing 1–10 of 42 orders" + Prev/Next (DESIGN.md §5). */
export function Pager({

  pageSize,
  total,
  noun,
  onPage,

  page: number
  pageSize: number
  total: number
  noun: string
  onPage: (page: number) => void

        <Button variant="outline" size="sm" disabled={page >= lastPage} onClick={() => onPage(page + 1)}>

        </Button>

/** Toolbar date filter (DESIGN.md §5: Popover + Calendar). Works in YYYY-MM-DD strings, '' for none. */
export function DatePicker({ label, value, onChange }: { label: string; value: string; onChange: (value: string) => void }) {
  const [open, setOpen] = useState(false)
  const parsed = value ? parseISO(value) : undefined
  const date = parsed && isValid(parsed) ? parsed : undefined
  return (
    <Popover open={open} onOpenChange={setOpen}>
      <PopoverTrigger asChild>
        <Button variant="outline" aria-label={`${label} date`} className="min-w-[135px] justify-start font-normal">
          <CalendarDays aria-hidden className="text-faint" />
          <span className="text-xs text-faint">{label}</span>
          {date && <span>{format(date, 'MMM d, yyyy')}</span>}
        </Button>
      </PopoverTrigger>
      <PopoverContent className="w-auto p-0" align="start">
        <Calendar
          mode="single"
          selected={date}
          defaultMonth={date}
          onSelect={(picked) => {
            onChange(picked ? format(picked, 'yyyy-MM-dd') : '')
            setOpen(false)
          }}
        />
      </PopoverContent>
    </Popover>
  )
}

import { keepPreviousData, useQuery } from '@tanstack/react-query'
import { serverLogic } from '@/api/serverLogic'
import type { OrderDto, OrdersPageDto } from '@/api/types'

export interface OrderFilters {
  q: string
  status: string
  site: string
  from: string
  to: string
  page: number
}

/** The endpoint's query string: empty filters and page 1 are left out. */
export function ordersQuery(filters: OrderFilters): Record<string, string> {
  const query: Record<string, string> = {}
  for (const key of ['q', 'status', 'site', 'from', 'to'] as const) if (filters[key]) query[key] = filters[key]
  if (filters.page > 1) query.page = String(filters.page)
  return query
}

/** A page of the customer's orders, filtered and paged in BC. The previous page stays on screen while the next loads. */
export function useOrders(filters: OrderFilters) {
  return useQuery({
    queryKey: ['orders', filters],
    queryFn: () => serverLogic<OrdersPageDto>('orders', { query: ordersQuery(filters) }),
    placeholderData: keepPreviousData,
    staleTime: 60_000,
  })
}

/** One order with its lines, fetched fresh each time the dialog opens. `null` = not found (missing or another customer's). */
export function useOrder(id: string | null) {
  return useQuery({
    queryKey: ['order', id],
    queryFn: async (): Promise<OrderDto | null> => {
      const answer = await serverLogic<OrderDto | { notFound: true }>('orders', { query: { id: id! } })
      return 'notFound' in answer ? null : answer
    },
    enabled: !!id,
    staleTime: 0,
  })
}

import { Button } from '@/ui/button'
import { Dialog, DialogContent, DialogDescription, DialogFooter, DialogHeader, DialogTitle } from '@/ui/dialog'
import { QueryError } from '@/ui/QueryError'
import { Skeleton } from '@/ui/skeleton'
import { Table, TableBody, TableCell, TableHead, TableHeader, TableRow } from '@/ui/table'
import { OrderStatusPill, siteLabel, tripNote } from './orderDisplay'
import { useOrder } from './useOrders'

/** The wireframe's View modal: details, BC lines and Order total, Trip ID note. Reorder arrives with New Order (S3). */
export function OrderDialog({ id, onClose }: { id: string | null; onClose: () => void }) {
  const order = useOrder(id)
  const sites = useSites().data ?? []
  const data = order.data
  const note = data && tripNote(data)

  return (
    <Dialog open={!!id} onOpenChange={(open) => !open && onClose()}>
      <DialogContent className="max-h-[calc(100vh-40px)] max-w-[720px] overflow-y-auto rounded-2xl p-[22px]">
        <DialogHeader>
          <DialogTitle className="font-mono">{id}</DialogTitle>
          <DialogDescription className="sr-only">Sales order details</DialogDescription>
        </DialogHeader>
        {order.isError ? (
          <QueryError onRetry={() => void order.refetch()} />
        ) : data === null ? (
          <p className="text-[13.5px] text-muted-foreground">We couldn't find this order.</p>
        ) : !data ? (
          <Skeleton className="h-40 w-full" />
        ) : (
          <>
            <dl className="grid grid-cols-1 gap-x-5 gap-y-2.5 rounded-lg bg-muted px-4 py-3.5 sm:grid-cols-2">
              {(
                [
                  ['Order date', formatDate(data.date)],
                  ['Status', <OrderStatusPill key="s" status={data.status} />],
                  ['PO reference', data.po || '—'],
                  ['Shipment method', data.ship === 'Pickup' ? 'Pick up' : data.ship ?? '—'],
                  ['Delivery site', siteLabel(data.site, sites)],
                  ['Expected delivery date', formatDate(data.edd)],
                  ['Blanket SO #', data.bso ?? '—'],
                  ['Trip ID number', data.trip?.id ?? '—'],
                ] as const
              ).map(([label, value]) => (
                <div key={label} className="flex flex-col gap-0.5">
                  <dt className="text-[11px] font-semibold tracking-wider text-faint uppercase">{label}</dt>
                  <dd className="text-[13.5px]">{value}</dd>
                </div>
              ))}
            </dl>
            <div className="overflow-hidden rounded-xl border">
              <Table aria-label="Order lines">
                <TableHeader>
                  <TableRow className="hover:bg-transparent">
                    {['Item', 'Qty', 'UOM', 'Unit price', 'Line total'].map((h, i) => (
                      <TableHead
                        key={h}
                        className={cn('bg-muted text-[11.5px] font-semibold tracking-wider text-faint uppercase', i % 2 && i !== 2 && 'text-right')}
                      >
                        {h}
                      </TableHead>
                    ))}
                  </TableRow>
                </TableHeader>
                <TableBody>
                  {data.lines.length === 0 ? (
                    <TableRow className="hover:bg-transparent">
                      <TableCell colSpan={5} className="py-[26px] text-center text-faint">
                        No items on this order.
                      </TableCell>
                    </TableRow>
                  ) : (
                    data.lines.map((line, i) => (
                      <TableRow key={`${line.code}-${i}`}>
                        <TableCell className="whitespace-normal">
                          {line.code} — {line.description}
                        </TableCell>
                        <TableCell className="text-right font-mono tabular-nums">{line.qty.toLocaleString('en-PH')}</TableCell>
                        <TableCell className="font-mono">{line.uom || '—'}</TableCell>
                        <TableCell className="text-right font-mono tabular-nums">{peso(line.unitPrice)}</TableCell>
                        <TableCell className="text-right font-mono tabular-nums">{peso(line.lineTotal)}</TableCell>
                      </TableRow>
                    ))
                  )}
                  <TableRow className="hover:bg-transparent">
                    <TableCell colSpan={4} className="text-right font-bold">
                      Order total
                    </TableCell>
                    <TableCell className="text-right font-mono font-bold tabular-nums">{peso(data.total)}</TableCell>
                  </TableRow>
                </TableBody>
              </Table>
            </div>
            {note && (
              <p
                className={cn(
                  'rounded-lg px-3.5 py-2.5 text-[13px]',
                  note.tone === 'good' ? 'bg-success-soft text-success' : 'bg-warning-soft text-warning',
                )}
              >
                {note.text}
              </p>
            )}
          </>
        )}
        <DialogFooter>
          <Button variant="outline" onClick={onClose}>
            Close
          </Button>
        </DialogFooter>
      </DialogContent>
    </Dialog>
  )
}
```
