# Customer Ledger Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Customer Ledger section built to the wireframe on sample data, plus a `ledger` Server Logic written against the field list we send the BC team as S2-07, with the deployed site keeping "coming soon" until BC delivers.

**Architecture:** A `ledger` Server Logic (same pattern as `orders`: session scope, filters/paging in BC, merged multi-query search) returns `LedgerPageDto`. The SPA's `LedgerPage` reuses the Orders list kit and keeps filters in the URL. Locally the dev `serverLogic` mock answers from the wireframe's `LEDGER_ENTRIES`; `SectionRoute` routes the page only in the local build until S2-07 lands.

**Tech Stack:** React 19, TypeScript, TanStack Query/Table, shadcn (Select, Popover/Calendar via `DatePicker`), Tailwind v4, Vitest + RTL, Power Pages Server Logic (plain JS, no modules).

**Spec:** `docs/superpowers/specs/2026-10-13-s2-c-ledger-design.md`

## Review Focus

1. A search that is only spaces or punctuation (e.g. `'`) must not break the BC filter: the term is trimmed, quotes doubled, and an empty trimmed term means "no search".
2. A due date of today (Manila) is **not** overdue; a due date yesterday with remaining 0 is **not** red; a negative remaining (credit) is never red.
3. A `page` past the end after a filter shrinks the list lands on the last page and never shows "No entries match" next to a non-zero count (same as Orders).
4. A BC `documentType` outside the three (e.g. `Refund`, `Finance_x0020_Charge_x0020_Memo`) shows under BC's name with spaces, and `?type=Refund` in the URL returns an empty page without a BC call.
5. The deployed build (`import.meta.env.DEV === false`) shows "This section is coming soon." on `/ledger`; the local build shows the page.

Each line has a test in the owning task (1 → Task 1 "blank and quote-only searches"; 2 → Task 2 `isPastDue`; 3 → Task 3 "page past the end"; 4 → Task 1 mapping + unknown type tests; 5 → Task 3 route test).

```js
// Server Logic: ledger (S2-08)
// Purpose: the signed-in customer's BC Customer Ledger Entries — filtered, searched and paged in BC.
// API URL: https://<site>/_api/serverlogics/ledger?q=&type=&show=all&from=&to=&page=
// Customer and company come only from the session's Account; request values only narrow the list.
// The BC entity and fields are the S2-07 request (docs/superpowers/specs/2026-10-13-s2-c-ledger-design.md) until BC confirms them.

async function get() {
    // #region bc-helpers (generated from server-logic-src/bc-helpers.js — do not edit)
    // #endregion bc-helpers

    var ENTITY = "customerLedgerEntries";
    var TYPES = ["Invoice", "Credit Memo", "Payment"];
    var PAGE_SIZE = 10;
    var SEARCH_CAP = "200";
    var FIELDS = "customerNo,postingDate,documentType,documentNo,externalDocumentNo,description,dueDate,amount,remainingAmount,open";
    var ORDER_BY = "postingDate desc,documentNo desc";
    var ISO_DATE = /^\d{4}-\d{2}-\d{2}$/;

    function param(name) {
        var params = Server.Context.QueryParameters || {};
        var value = params[name];
        return value === undefined || value === null ? "" : String(value).trim();
    }

    // Dates go into the filter unquoted: only a real calendar date in YYYY-MM-DD form (2026-02-30 is dropped too).
    function isoDate(value) {
        if (!ISO_DATE.test(value)) {
            return false;
        }
        var date = new Date(value + "T00:00:00Z");
        return !isNaN(date.getTime()) && date.toISOString().slice(0, 10) === value;
    }

    function bcDate(value) {
        return value && value !== "0001-01-01" ? value : null;
    }

    function toEntry(row) {
        return {
            docNo: row.documentNo || "",
            refPo: row.externalDocumentNo || null,
            type: String(row.documentType || "").split("_x0020_").join(" "),
            desc: row.description || "",
            postingDate: row.postingDate || "",
            dueDate: bcDate(row.dueDate),
            original: Number(row.amount) || 0,
            remaining: Number(row.remainingAmount) || 0,
            status: row.open ? "Open" : "Closed"
        };
    }

    function newestFirst(a, b) {
        if (a.postingDate !== b.postingDate) {
            return a.postingDate < b.postingDate ? 1 : -1;
        }
        return a.documentNo < b.documentNo ? 1 : a.documentNo > b.documentNo ? -1 : 0;
    }

    function listFilter(scope, type) {
        var parts = ["customerNo eq " + odataLiteral(scope.customerNo)];
        var from = param("from");
        var to = param("to");
        if (param("show") !== "all") {
            parts.push("open eq true");
        }
        if (type) {
            parts.push("documentType eq " + odataLiteral(type));
        }
        if (isoDate(from)) {
            parts.push("postingDate ge " + from);
        }
        if (isoDate(to)) {
            parts.push("postingDate le " + to);
        }
        return parts.join(" and ");
    }

    // BC's contains() is case-sensitive and BC can't "or" two fields: document and PO numbers are Code fields (stored
    // upper case); descriptions are searched as typed, lower case and Capitalised. One query per distinct term.
    function searchTerms(q) {
        var upper = q.toUpperCase();
        var lower = q.toLowerCase();
        var terms = [["documentNo", upper], ["externalDocumentNo", upper]];
        [q, lower, upper.charAt(0) + lower.slice(1)].forEach((variant) => {
            if (!terms.some((term) => term[0] === "description" && term[1] === variant)) {
                terms.push(["description", variant]);
            }
        });
        return terms;
    }

    async function list(scope, page) {
        var type = param("type");
        if (type && TYPES.indexOf(type) === -1) {
            return { entries: [], total: 0, page: page, pageSize: PAGE_SIZE };
        }
        var filter = listFilter(scope, type);
        var mine = (row) => row.customerNo === scope.customerNo;
        var q = param("q").slice(0, 50);
        if (!q) {
            var result = await bcGet(
                scope,
                ENTITY,
                odataQuery({
                    $filter: filter,
                    $select: FIELDS,
                    $orderby: ORDER_BY,
                    $top: String(PAGE_SIZE),
                    $skip: String((page - 1) * PAGE_SIZE),
                    $count: "true"
                })
            );
            var rows = ((result && result.value) || []).filter(mine);
            var count = Number(result && result["@odata.count"]);
            return { entries: rows.map(toEntry), total: isNaN(count) ? rows.length : count, page: page, pageSize: PAGE_SIZE };
        }
        var results = await Promise.all(
            searchTerms(q).map((term) =>
                bcGet(
                    scope,
                    ENTITY,
                    odataQuery({
                        $filter: filter + " and contains(" + term[0] + "," + odataLiteral(term[1]) + ")",
                        $select: FIELDS,
                        // ponytail: newest 200 per query (as orders); page through BC if a customer's searches ever need more.
                        $orderby: ORDER_BY,
                        $top: SEARCH_CAP
                    })
                )
            )
        );
        var merged = [];
        var seen = {};
        results.forEach((res) => {
            ((res && res.value) || []).filter(mine).forEach((row) => {
                var key = row.documentType + "|" + row.documentNo + "|" + row.postingDate;
                if (!seen[key]) {
                    seen[key] = true;
                    merged.push(row);
                }
            });
        });
        merged.sort(newestFirst);
        var start = (page - 1) * PAGE_SIZE;
        return { entries: merged.slice(start, start + PAGE_SIZE).map(toEntry), total: merged.length, page: page, pageSize: PAGE_SIZE };
    }

    Server.Logger.Log("ledger GET called");
    return respond(async () => {
        var scope = await sessionScope();
        var page = parseInt(param("page"), 10);
        return list(scope, isNaN(page) || page < 1 ? 1 : Math.min(page, 1000));
    });
}

import { keepPreviousData, useQuery } from '@tanstack/react-query'
import { serverLogic } from '@/api/serverLogic'
import type { LedgerPageDto } from '@/api/types'

export interface LedgerFilters {
  q: string
  type: string
  /** 'all' for All entries; '' = Open items only (the default). */
  show: string
  from: string
  to: string
  page: number
}

/** The endpoint's query string: empty filters and page 1 are left out. */
export function ledgerQuery(filters: LedgerFilters): Record<string, string> {
  const query: Record<string, string> = {}
  for (const key of ['q', 'type', 'show', 'from', 'to'] as const) if (filters[key]) query[key] = filters[key]
  if (filters.page > 1) query.page = String(filters.page)
  return query
}

/** A page of the customer's ledger entries, filtered and paged in BC. The previous page stays on screen while the next loads. */
export function useLedger(filters: LedgerFilters) {
  return useQuery({
    queryKey: ['ledger', filters],
    queryFn: () => serverLogic<LedgerPageDto>('ledger', { query: ledgerQuery(filters) }),
    placeholderData: keepPreviousData,
    staleTime: 60_000,
  })
}

          else next.delete(key)
        }
        if (!('page' in changes)) next.delete('page') // any filter change starts again at page 1
        return next
      },
      { replace: true },
    )
  }

  // Search waits for typing to stop (~300 ms) so not every keystroke calls BC.
  useEffect(() => {
    if (search.trim() === filters.q) return
    const timer = window.setTimeout(() => update({ q: search.trim() }), 300)
    return () => window.clearTimeout(timer)
  }, [search])

  const data = ledger.data
  const lastPage = data ? Math.max(1, Math.ceil(data.total / data.pageSize)) : 1
  // A page past the end (old link, or a filter shrank the list) lands on the last page.
  useEffect(() => {
    if (data && !ledger.isPlaceholderData && filters.page > lastPage) update({ page: lastPage > 1 ? String(lastPage) : '' })
  }, [data, filters.page, lastPage, ledger.isPlaceholderData])

  const today = manilaToday()

  return (
    <>
      <PageHeader title="Customer Ledger" />
      <SectionCard title="Customer Ledger">
        <Toolbar
          onClear={() => {
            setSearch('')
            setParams(new URLSearchParams(), { replace: true })
          }}
        >
          <SearchField
            label="Search ledger entries"
            placeholder="Search document no., Ref PO, or description"
            value={search}
            onChange={(event) => setSearch(event.target.value)}
            className="max-w-[260px]"
          />
          <Select value={filters.type || ALL} onValueChange={(value) => update({ type: value === ALL ? '' : value })}>
            <SelectTrigger aria-label="Filter by document type" className="w-[190px]">
              <SelectValue />
            </SelectTrigger>
            <SelectContent>
              <SelectItem value={ALL}>All document types</SelectItem>
              {LEDGER_TYPES.map((type) => (
                <SelectItem key={type} value={type}>
                  {type}
                </SelectItem>
              ))}
            </SelectContent>
          </Select>
          <Select value={filters.show || OPEN} onValueChange={(value) => update({ show: value === OPEN ? '' : value })}>
            <SelectTrigger aria-label="Show open items or all entries" className="w-[170px]">
              <SelectValue />
            </SelectTrigger>
            <SelectContent>
              <SelectItem value={OPEN}>Open items only</SelectItem>
              <SelectItem value="all">All entries</SelectItem>
            </SelectContent>
          </Select>
          <DatePicker label="From" value={filters.from} onChange={(from) => update({ from })} />
          <DatePicker label="To" value={filters.to} onChange={(to) => update({ to })} />
        </Toolbar>
        {ledger.isError ? (
          <QueryError onRetry={() => void ledger.refetch()} />
        ) : (
          <>
            <DataTable
              label="Customer ledger"
              columns={columns(today)}
              data={data?.entries ?? NO_ENTRIES}
              // Also while jumping back from a page past the end, so the table never says "no entries" next to a count.
              loading={ledger.isPending || filters.page > lastPage}
              emptyMessage="No entries match your filters."
              className="shadow-none"
            />
            {data && (
              <Pager
                page={Math.min(filters.page, lastPage)}
                pageSize={data.pageSize}
                total={data.total}
                noun="entry"
                plural="entries"
                onPage={(page) => update({ page: page > 1 ? String(page) : '' })}
              />
            )}
          </>
        )}
      </SectionCard>
    </>
  )
}
```

Note: `columns(today)` is rebuilt per render; `DataTable` requires stable `data`, not stable columns (Orders memoises columns only because they close over sites). If the TanStack table warns about columns identity, wrap it: `const tableColumns = useMemo(() => columns(today), [today])`.
